# Aplikasi Toko Buku (Android)
Aplikasi toko buku arya duta berbasis java android dengan database firebase cloud firestore. Aplikasi ini dibuat pada minimum API Level 21 (Android versi 5.0 Lollipop) dan terdapat 2 hak akses yakni user yang dapat melakukan pembelian dan admin yang dapat memanagement data serta memproses pengiriman pesanan. 

Created by: Ifan Ferdiansyah (Instagram: [@_ifanferdi](https://www.instagram.com/_ifanferdi), Twitter: [@_ifanferdi](https://twitter.com/_ifanferdi))
